## 1. Executive Summary

`kyty-prospero` already has a remarkably advanced baseline compared to early PS5 emulators:
- Full Vulkan 1.3 Dynamic Rendering & Synchronization2 backend (`VK_KHR_push_descriptor`, `bufferDeviceAddress`, `shaderBufferInt64Atomics`, `timelineSemaphore`).
- Existing `spirvEmitterMesh.cpp`, `spirvEmitterBvh.cpp`, `spirvEmitterRayQuery.cpp`, and `rayTracing.cpp` (host BLAS/TLAS mirroring for guest BVH formats 1/3/6/10).
- Broad `libSce*` HLE coverage (`libAmpr`, `libAudio2`, `audio3d`, `ajm`, `ngs2`, `libVideoOut`, `libPad`, `libPlayGo`, `libTrophy`).

## 2. Core Bottleneck Map (Evidence-Based)

### A. RDNA 2 (`GFX10.3`) → SPIR-V 1.6 Shader Recompiler Gaps
1. **Incomplete 64-Bit `MUBUF` Buffer Atomics (`MemoryOps.cpp:74-78`, `Memory.cpp:1023-1057`, `spirvEmitterMemory.cpp`):**
   - Only 5 of 11 64-bit buffer atomics are implemented (`SWAP_X2`, `ADD_X2`, `UMIN_X2`, `AND_X2`, `OR_X2`).
   - **Missing:** `BUFFER_ATOMIC_CMPSWAP_X2` (`0x51`), `BUFFER_ATOMIC_SUB_X2` (`0x53`), `BUFFER_ATOMIC_SMIN_X2` (`0x55`), `BUFFER_ATOMIC_SMAX_X2` (`0x57`), `BUFFER_ATOMIC_UMAX_X2` (`0x58`), and `BUFFER_ATOMIC_XOR_X2` (`0x5b`).
   - **AAA Impact:** **Direct UE5 Nanite blocker.** Nanite's software rasterizer packs `(32-bit reverse-Z depth << 32) | 32-bit visibility payload` and updates the visibility buffer using **`BUFFER_ATOMIC_UMAX_X2` (`0x58`)**. Lock-free GPU page/cluster allocators rely on **`BUFFER_ATOMIC_CMPSWAP_X2` (`0x51`)**. Every affected shader currently fails with `MUBUF opcode is not implemented`.
2. **Hard Crash on Partial `S_WAITCNT_VSCNT` Store Waits (`Control.cpp:172-178`):**
   - `psslc` emits pipelined `s_waitcnt_vscnt null, N` (`N = 1..62`) to overlap vector stores with ALU work.
   - `Control.cpp:174` currently executes `EXIT("unsupported partial or register-based S_WAITCNT_VSCNT")` for any `count` outside `{0, 63}`, immediately crashing valid AAA shaders instead of emitting a conservative `StoreCompletion` barrier.
3. **Missing `FLAT` / `GLOBAL` Atomics (`MemoryOps.cpp:102-111, 425`):**
   - `FLAT_OPCODE_LIST` contains only loads/stores; zero `GLOBAL_ATOMIC_*` / `FLAT_ATOMIC_*` opcodes are decoded, and `glc=1` is rejected in `DecodeFlat`.
4. **Missing RDNA 2 `VOP3` / `VOP3P` Opcodes (`VectorAluOps.cpp`):**
   - Missing `V_MAD_I64_I32` (`0x177`), IEEE-754 division helpers (`V_DIV_SCALE_F32/F64`, `V_DIV_FMAS_F32/F64`, `V_DIV_FIXUP_F32/F64`), and `VOP3P` DP4a dot-product ops (`V_DOT4_I32_I8`, `V_DOT4_U32_U8`).
5. **Compute-Only Shader Function Calls (`ShaderCalls.cpp:27`):**
   - `EXIT_NOT_IMPLEMENTED(options.stage != ShaderType::Compute)` blocks Vertex/Fragment/Mesh shaders using `S_SWAPPC_B64`.
6. **Strict `S_GETREG_B32` Whitelist (`Scalar.cpp:21-27`):**
   - Crashes on hardware register queries outside `HW_ID2` (`0x1818` / `0x0a18`).

### B. Host GPU / Vulkan 1.3 Synchronization & Pipeline Gaps
1. **Single Universal Queue Serialization (`vulkanWindow.cpp:123`):**
   - Graphics and Async Compute workloads share a single universal queue; splitting out a dedicated async compute queue with timeline-semaphore handoff will eliminate cross-queue bubbles in heavy compute-driven frames (Lumen / Nanite / Virtual Shadow Maps).
2. **BVH Readback Ring Saturation (`rayTracing.h`):**
   - Dynamic BLAS/TLAS mirroring uses 8 readback areas; heavy dynamic RT scenes can stall waiting for readback slots.

### C. PS5 OS HLE Libraries (`src/libs/`, `src/kernel/`, `src/loader/`)
1. **Missing `libSceFios2` Module:** Not present in `src/libs/`; games using FIOS2 streaming fall into `UnresolvedImportStub`.
2. **High-Density Unimplemented Paths (`EXIT_NOT_IMPLEMENTED` / stubs):**
   - `ngs2.cpp` (132), `agc.cpp` (121), `pthread.cpp` (44), `network.cpp` (29), `audio3d.cpp` (25), `ajm.cpp` (23), `libKernel.cpp` (18), `fileSystem.cpp` (14).
3. **Unresolved NID Triage (`runtimeLinker.cpp`):** Stubs return `0` and print raw lines without grouped per-library missing-NID summaries.

## Phase 2 — Next Recommended Breakthroughs
With Core Breakthrough #17 certified, the highest-impact next steps are:
1. **Core Breakthrough #18 (Live Boot & Shutdown Runtime Wiring + Async Compute / BVH Ray-Query Optimization):** Wire `Common::BootTelemetry` milestones (`elf_loaded`, `first_gpu_submit`, `first_frame_presented`) and `SaveVkPipelineCacheBlob`/`LoadVkPipelineCacheBlob` directly into `main.cpp` / `runtimeLinker.cpp` / `graphicsRun.cpp` / `renderer.cpp` live lifecycle hooks, plus optimize `VK_KHR_ray_query` BVH mirror updates and `AsyncPipelinePrewarmer` submission from the live shader cache.
2. **Core Breakthrough #19 (`VK_EXT_shader_object` / Bindless Descriptor Heap Fast-Path):** Eliminate graphics pipeline permutation stutter in UE5/AAA open-world streaming by introducing a `VK_EXT_shader_object` fast-path where supported by host Vulkan 1.3 drivers and streamlining bindless descriptor updates.
